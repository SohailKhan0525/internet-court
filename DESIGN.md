# Unslop direction

- Product: Put everyday arguments before a court of public opinion.
- Character: Wry, considered, human.
- World: Paper case files, marginal notes, courtroom engraving, warm ivory and burgundy ink.
- Moments: An engraved gavel beside the disputed pizza slice; a paper case file and interactive jury panel.
- Signature: Case numbers and a restrained verdict stamp.

## Audit and nine passes

The original page already had a useful courtroom premise and strong copy. It had uppercase tracked labels, inconsistent small spacing, plain repeated sections, an undistinguished example card, and a membership call to action tied to the prior app. The user explicitly requested a clean replacement.

1. Spacing: consistent 4px-based spacing, generous section rhythm, related content grouped tightly.
2. Color: warm neutral surfaces, three text roles, one oxblood accent.
3. Icons: a small consistent line-icon vocabulary; no emoji or decorative badges.
4. Copy: kept the product name and central line; made all sample and local-only behavior explicit. Removed unverified activity, pricing, and availability claims.
5. Type: editorial Fraunces display and readable DM Sans interface. Regular headings, sentence case, tabular case numbers.
6. Layout: asymmetric hero, ordered procedure, sample docket, comparison, FAQ, closing action. Mobile content follows reading order.
7. Details: paper folder edge, case reference numbers, proper selected states, keyboard focus, semantic tabs and dialogs.
8. Visuals: one original engraved gavel-and-pizza illustration beside a real coded case preview. Fixed dimensions prevent layout shift.
9. Motion: short color feedback only, no looping animation, no parallax, reduced-motion support.

## Image prompt

Built-in OpenAI image generation, 1536 × 1024: antique copperplate engraving in a single deep oxblood burgundy ink (#71312e) on flat warm ivory (#f7f4ee). One wooden judge’s gavel resting diagonally against a sound block, with one small pizza slice as the absurd evidence on trial. Fine crosshatched lines, dignified but quietly funny newspaper illustration. Wide 3:2 composition with empty margins. No text, logos, UI, border, grain, gradients, or watermark.
